五模型调速范围计算接入说明
2026-11-20

1. 模型和坐标
业务模型编号为2单点、3多级升降、4无极旋转、7普通多点摆、9XY多点摆。
单点和多级升降的每根实轴位置为H，电机速度按H导数计算。
无极旋转4只有H有效，所有实轴直接跟随同一个H角度；P/Y模板项填0，不得包含运动。实轴峰速与H峰速相同，不需要多点几何参数。
无极必须传现有字段workingStroke及min_position_HPY、max_position_HPY：workingStroke为PLC所有绑定实轴共同的真实正周期，H软行程满足0<=下限<上限<=workingStroke，绑定实轴数为1到32，与PLC的oneModelMaxAxisNum一致。
workingStroke不能硬码360，也不能用软行程宽度代替。H位置、速度、加减速度使用PLC技术单位及其每秒、每秒平方；周期360度时通常为degree、degree/s、degree/s²。
全周期软行程[0,workingStroke]由PLC轴MODULO处理，输入保留真实连续H系数，例如350到370经过360零点；算法不把位置取模后的数值跳变当成速度，也不自行改变原系数或选择最短路径。
也支持在系数阶段边界按周期归零，例如359到360后下一阶段0到1；这与连续展开359到361具有相同的V/A/D及倍率。这里的周期归零仍是同向运动，不等于实际反向；真实反向由原系数导数符号体现。
若原系数本来描述359到1的连续反向358单位运动，仍按其真实导数计算；若实际计划正向跨零2单位，应提供359到361的执行系数。非强制也须传入PLC实际Move执行曲线的系数。
部分软行程保持线性上下限，算法检查整段H及其内部极值，越过禁用区时明确报错，不能用周期折回掩盖越界。调速不改变位置路径，合法路径的周期和软行程不会额外缩小倍率。
多级升降3在PLC内部段点数为0时按普通H运动计算。范围算法无需nSections、AdjustDistance或deceleration_ratio，0点时这三个字段都可省略，或传nSections=0、AdjustDistance=[]。
存在内部段点时，segments或coefficient_segments应填写PLC最终实际执行的H曲线，将经过段点的速度变化纳入系数；范围算法直接从该H曲线求V/A/D峰值。
普通多点HPY为高度/倾角/方向角，XY的HPY为高度/X倾角/Y倾角。
长度单位mm，角度单位degree，速度单位分别为mm/s和degree/s。
普通多点倾角及XY两个倾角处于(-90,90)内，XY的betainit为0。
吊点按真实轴顺序传入，支持二维或三维坐标。边距由凸包计算，全部实轴保留输入顺序。
普通多点摆至少3个非共线吊点。XY多点摆支持2个吊点；双点须位于同一X轴或Y轴，线段包含原点、两点不重合且Z为0，允许一个端点位于原点。
最终PLC为双点保存两个线段端点，双点正算将水平偏移置0。算法采用相同零偏移正算，实轴位置与速度按固定X轴、固定Y轴旋转及线长变化计算。XY三个及以上吊点沿用原凸包逻辑。
XY两个角的最大速度使用PLC保存的REAL数值，例如3.9degree/s按3.9限制，不先取整。

2. 输入与返回
输入包含command、settings、models，算法参数.json给出逐字段说明及五模型示例。
command.trajectory_run为true时按强制轨迹计算，为false时执行非强制的动作分类与速度范围计算。
settings.forced_coefficient_time_unit_ms规定abcdef自变量的时间单位。
models放完整原动作曲线、真实max_velocity_HPY、max_motor_velocity及几何参数。
每段可含coefficient_segments，连续覆盖原段起止时间。多级过点减速按最终执行H曲线填写。
原动作按100%传入。虚轴上限除以原曲线峰速，实轴上限除以正解得到的电机峰速，再与已提供的A/D能力约束一起取整个动作最严倍率。
max_acceleration_HPY、max_deceleration_HPY沿用已有字段且均可省略。调速采用V乘倍率、A/D乘倍率平方；缺少哪一项，就不追加该项能力限制。
原表按速度幅值增大归A、减小归D，速度过零时分段判断。峰值由原abcdef多项式及其导数计算，包含阶段端点、速度零点、加速度零点和jerk零点。
此范围接口没有方向字段，返回正向、反向共同可用的范围。时间反向后A/D角色互换，因此逐轴取原表A/D峰值的较大值，分别用sqrt(最大A/双向峰值)、sqrt(最大D/双向峰值)约束已提供的能力；每轴单独计算后再取动作最严倍率。
max_factor为倍率，1表示100%。max_factor=null且unlimited=true表示全程速度约束没有有限倍率上限。
action_category给出动作分类，action_signature绑定models/settings/运行方式，range_version本版为shared_json_v2。
上位机须重新计算旧range_result，不能复用shared_json_v1的仅速度约束缓存。上位机使用缓存前同时核对range_version和action_signature，任一不符即重新调用calculate_range_result。在线调速Python由上位机提供允许倍率，上位机负责这项缓存检查。
更新算法或原动作、限速、几何后重新计算range_result。

3. API及命令行
from 调速范围计算 import calculate_range_result
range_result = calculate_range_result(parameters)
API返回结果字典，调用方捕获异常并显示错误原因。
python 调速范围计算.py
python 调速范围计算.py 算法参数.json
命令行把结果保存至同一JSON的range_result，保留其它请求和结果。

4. 计算依据
正解按YXZ_new.py对照，普通多点采用倾角与方向角，XY采用固定X轴、固定Y轴的顺序旋转。
普通多点的原Z在旋转后叠加，XY原Z参与两次旋转。
实轴峰速由解析瞬时速度和整段区间上界共同求取，分段时检查内部极值及相位边界。
单点及多级升降的H峰速、所有模型H/P/Y峰速均包含高阶内部极值。
所有模型的虚轴最大速度和实轴最大速度共同参与整个动作倍率计算。
非强制中单点/多级升降/无极旋转均为单虚轴直接映射，均可升速、降速，最终受真实V/A/D能力约束；同步非单点、不同步非单点沿用相应分类上限。

5. 文件与核验
本包包括算法、带字段说明的输入JSON、本说明和本次测试报告。
算法通过Python标准库独立运行。
离线测试采用参考文件的原正解函数AST及基础数组操作替身，另进行有限差分及区间采样对照。
实轴峰值采用双精度数值上界，复杂段在细分预算内可能得到偏保守的范围。
