就近/同步准备：指定帧与方向搜索两种方式，2026-10-28

1. 上位机只需要本包四个文件
就近接入计算.py、算法参数.json、接入说明.txt、本次接口测试报告.txt。
与另两个算法分别解压；三算法的models/settings结构及本例静态数据保持一致。

2. 两种方式用哪个标志
复用已有command.use_specified_time，不新增重复标志。

方式一：固定接入传入帧
    nearest_start=true
    use_specified_time=true
    specified_time_ms=3500
    stopped_time_ms=null
最终selected_curve_time_ms必须等于3500。reverse决定之后的运行方向，不改变固定目标。
即使nearest_start=false，显式use_specified_time=true也以指定帧为准。

方式二：从参考帧按方向寻找位置最接近的接入点
    nearest_start=true
    use_specified_time=false
    specified_time_ms=0
    stopped_time_ms=3500
    reverse=false
    selection_metric="nearest_position"
当前位置放runtime.models[].position_HPY，必须传整个动作的全部模型。
正向只搜索[3500,动作末帧]；reverse=true时只搜索[动作首帧,3500]。
3500只是搜索边界，最终输出可以是5000等其他帧，不是收到3500就直接跑3500。
不跨下一循环；停止帧超出当前动作首末范围则拒绝，不悄悄改跑起终点。
stopped_time_ms=null时，从方向起点搜索整个动作；0是有效帧，不能当成未提供。

保留原有普通启动：use_specified_time=false、nearest_start=false时，正向首帧、反向末帧。
这两种接入方式与普通启动规则同时适用于强制和非强制；准备运动仍沿用各自原计算。

3. “位置最接近”的比较方法
对所有模型的活动轴计算abs(目标位置-实际位置)/本轴最大速度，再取最大值。
这是沿用原算法的归一化位置代价，避免直接将高度mm与角度degree相加。
本版默认nearest_position。非强制相同位置代价时，再比较可执行准备时间和方向先后。
minimum_prepare_time仍可显式选择非强制旧时间优先方式；它可能选更远但准备更快的帧。
强制沿用位置代价粗搜/细搜，相同代价按运行方向选先遇到的帧。
强制精度受coarse_step_ms/fine_step_ms约束，未宣称任意高阶曲线的连续全局最近点。
非强制在nonforced_frame_step_ms配置网格及原段边界中搜索，整段q/v核对不变。

4. 输入及调用
command：两种方式、trajectory_run、reverse、speed_factor及循环配置。
models：原动作全部模型的几何、能力、行程与原始曲线；当前位置不写进models。
settings：单位、协议精度、搜索步长等原设置，本例与另两个算法的静态设置相同。
runtime.models：通过model_id关联的实际位置、速度和停稳反馈；就近输入必须已停稳。
plc_id为非空字符串路由标识；device_id是组报文用的设备编号。

API：
    from 就近接入计算 import calculate_nearest_entry
    result = calculate_nearest_entry(parameters)
API不修改输入字典。
F5/命令行：python 就近接入计算.py
显式文件：python 就近接入计算.py 算法参数.json
新公共文件CLI只更新nearest_result；旧就近接入参数.json仍另存独立结果文件。

5. 上位机使用哪个结果
检查status=planned后，使用selected_curve_time_ms作为最终公共接入帧。
不要把输入stopped_time_ms直接下发为目标帧。
frame_selection_mode说明实际模式；reference_frame_ms说明输入参考；search_range_ms说明搜索范围。
prepare_time_ms是从共同释放T0起的准备耗时，与原曲线帧不是同一个时间。

强制：使用1006_payloads内的selectedCurveTimeMs、prepareTimeMs和各设备V/A。
按当前PLC实际描述文件编码1006；1007仍以共同T0释放准备，所有PLC使用同一公共帧和准备时间。
本次未修改PLC协议字段宽度或运动保护逻辑。
非强制：完整执行axis_plans.move_steps及continuation_axis_moves，仍使用可编码V/A/D。
准备下发时刻=T0+start_offset_ms；接续时刻=T0+prepare_time_ms+start_offset_after_join_ms。
join_position_HPY/join_velocity_HPY是接入状态，move_target是实际Move停车目标，二者可以不同。
不能只取第一条Move，也不能等准备Move Done才按旧时间表接续。
can_dispatch=false保留原含义：旧1006/1007不能直接表达非强制带速轴队列，不能硬套。
