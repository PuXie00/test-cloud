# Control-page Action Sequence Preview — Interaction Design

Date: 2026-09-16

控制页执行前需要快速确认「这条序列长什么样、要跑多久、过程是否合理」。今日 3D 姿态预览只跟动作页时间轴游标走，控制页 F 槽 / 节目列表没有预览入口。预览使用频率高，交互必须少点击、不打断 Ready/GO。

## Goal

在控制页用同一套轻量预览，覆盖两类需求：

1. **静态概览**：大致空间轨迹 + 时长（及参与物体）。
2. **过程预览**：在 3D 里按时间播放/拖 scrub，看运行过程。

全程本地求值，不发 PLC，不占用执行槽。

## Non-goals

- 不替代 Ready / GO，不下载、不同步、不启动真实运动。
- 不打开对话框、不跳动作页、不新增右栏 Tab。
- 不做碰撞/限位精确校验可视化（轨迹是「大致」）。
- 不按推子速度比例预览（推子只作用于真实 GO）。
- 不在有真实 GO 运行时抢 3D 主姿态（见冲突规则）。
- 本方案只定交互与信息架构，不改 3D 引擎 API、不画实现。

## Locked decisions

| Topic | Decision |
|---|---|
| 入口 | **单击选中即预览**。点 F 槽序列名，或点节目列表该行。无单独「预览」按钮 |
| 落点 | 现有 3D 视口 + 视口顶栏一条预览条。不弹窗、不加底栏 |
| 两层预览 | 选中后立刻出层 1（轨迹+时长）；层 2 用同一条上的播放/scrub，不换模式 |
| 默认 | 选中后停在 **t = 0**，**不自动播放**（先看轨迹和总时长） |
| 播放 | 顶栏 ▶ / 空格 播放或暂停；播完停在终点，不循环 |
| 时间 | `elapsed / total`，格式与活跃任务相同：`00:12.3 / 01:00.0` |
| 轨迹 | 按 100ms 采样的物体路径折线，示意用，非碰撞真值 |
| 成员 | 沿用动作页：非本序列物体变淡 |
| 颜色 | 预览条与轨迹用 rehearsal/`secondary`；真实运行仍用 `show`。二者不得同色 |
| 推子 | 预览 1× 编排时长，忽略 F 槽 % |
| 与 GO | Ready/GO 交互不变。有任一活跃任务 `running` 时，3D 主姿态跟真实运行；预览条禁用并提示「运行中」 |
| 切换 | 再点另一条序列名/行，立即切到那条预览（无需确认） |
| 退出 | Esc、点空白 F 槽、或预览条 × 。退出后 3D 回到安装/实时位姿 |
| 待修复 | 能求值则仍可预览，条上警告 chip；求值失败则无轨迹，条上「无法预览」 |
| 演出模式 | 同样可用（看轨迹的需求在演出前更高，不隐藏） |

## Why this shape

F 槽最窄 72px，再塞预览键会误触 Ready。弹窗对「连看 F2、F3、F4」太重。悬停预览路过 8 槽会乱闪。

因此：**选中 = 预览**；播放是选中之后的第二下（或空格）。

```
点序列名/节目行
        │
        ▼
3D：成员高亮 + 轨迹折线 + t=0 姿态     顶栏：名称 · 00:00.0 / 总时长 · ▶
        │
        ├─ ▶ / 空格  → 过程预览（本地播放）
        ├─ 拖时间条  → 跳到任意时刻
        └─ Ready/GO  → 仍走执行，与预览无关
```

## Surfaces

### 1. F 槽（主入口）

- **可点区域**：序列名称（及名称所在标题行），不是推子、不是 Ready/GO。
- **选中态**：槽左侧 2px `secondary` 条，与 Ready（`primary` 边）和运行中（`show` 边）区分。
- 名称旁用 `font-mono` 显示总时长（如 `08.0` 或 `01:12.0`），一眼能扫 8 槽。
- Hover 名称：指针 `pointer`，tooltip「预览」。

### 2. 节目列表（次入口）

- 单击行 = 同一预览目标（仍不 launch）。
- `aria-selected` 表示预览选中。
- 行上已有时长则复用，不再加按钮。

### 3. 3D 视口顶栏预览条

选中后出现在视口顶栏右侧（监控/操作/节目按钮左侧），一条、不换行：

```
┌ 视口顶栏 ──────────────────────────────────────────────┐
│ 视图菜单          [ 斜面A  00:03.1 / 00:08.0  ▶  × ] 监控 操作 节目 │
└────────────────────────────────────────────────────────┘
```

| 元素 | 行为 |
|---|---|
| 名称 | 当前预览序列，截断 |
| 时间 | `当前 / 总时长`，`font-mono tabular-nums` |
| 时间条 | 名称与按钮之间一条细 scrub（高 4px，命中区 16px） |
| ▶ / ⏸ | 播放或暂停 |
| × | 退出预览 |

未选中时预览条不出现，顶栏保持现状。

### 4. 3D 画布

选中且无真实运行时：

- 非成员变淡。
- 每个参与物体一条 `secondary` 轨迹折线（大致路径）。
- 物体姿态 = 当前预览光标（默认 0；播放/scrub 后为该时刻）。
- 播放时物体沿折线走，光标同步。

有真实运行时：画布跟活跃任务；轨迹可保留浅色 Ghost，但物体主姿态不跟预览光标。

## Flows

### 扫一眼时长与轨迹（最高频）

1. 点 F3 名称。
2. 顶栏出现总时长；3D 出轨迹和起始姿态。
3. 看完点 F4 名称，预览立刻换成 F4。

目标：**一下**。

### 看运行过程

1. 已选中。
2. 空格或 ▶，1× 播放。
3. 再按空格暂停；拖 scrub 微调。
4. 结束停在终点，需再看则点时间条开头或再按 ▶（从 0 重播）。

目标：选中之后 **一下** 开播。

### 预览后执行

1. 预览 F3。
2. 直接按该槽 Ready → GO。预览可保留到 GO 成功。
3. GO 成功后预览条禁用（运行中）；活跃任务按现有逻辑出现。

### 节目列表

1. 打开右栏「节目」。
2. 点某行，3D 预览该序列（即使它不在当前 F 页）。
3. 若该序列也在当前页 F 槽，对应槽同步选中态。

## Keyboard

| 键 | 条件 | 动作 |
|---|---|---|
| Space | 已选中且无真实运行 | 播放 / 暂停 |
| Esc | 已选中 | 退出预览 |
| ← / → | 已选中 | 光标 ±100ms |
| Home / End | 已选中 | 跳到 0 / 终点 |

不拦截输入框内空格。不给 F 槽加第二套快捷键，避免和 Ready 抢手。

## Edge cases

| 情况 | 行为 |
|---|---|
| 空槽 | 点名称区域无操作；点空白可退出预览 |
| 求值失败 | 无折线；条上「无法预览」；▶ 禁用 |
| 待修复但仍能求值 | 可预览；条上 warning chip，Ready 仍按现有规则拦截 |
| 时长 0 | 只显示起始姿态，无折线或单点；▶ 禁用 |
| 指令-only（无位移） | 无空间折线；仍显示时长并播放（姿态可不变） |
| 正在 Ready | 仍可预览（本地）；不取消 Ready |
| 正在 GO / 活跃任务 running | 3D 主姿态跟运行；预览条禁用 |
| 切控制页离开再回来 | 不保留预览选中（避免和现场位姿错位） |
| 演出模式 | 入口与排练相同 |

## Visual tokens

- 预览选中条、轨迹、预览时间：`secondary` / rehearsal 蓝紫，不用 `show` 绿。
- 预览条容器：`bg-muted`，与顶栏半透明底分层，不要和画布同色。
- 时间数字：`font-mono text-mono-sm tabular-nums`。
- 轨迹线宽保持细（约 1–2px），避免挡住物体。

## Out of scope for later

- 轨迹上标注关键位姿时刻。
- 预览倍速（0.5× / 2×）。
- 多序列同时 Ghost。
- 预览结果写回 PLC 或自动 Ready。

## Implementation notes (not this phase)

现有 `evaluateResolvedSequence(resolveActionSequence(seq), cursorMs)` 已能出任意时刻姿态；动作页 `useActionPreviewPoses` 只读时间轴 `cursorMs`。控制页预览应接 **独立的 preview cursor**，不要复用动作页 dock 游标。轨迹折线对 `totalMs` 按 100ms 采样同一求值函数即可。
